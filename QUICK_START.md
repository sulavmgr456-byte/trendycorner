# 🚀 Quick Start Guide

**Welcome to your Trendy Corner website!** Get started in 5 minutes.

## Step 1: Test Locally (1 minute)
Open `Home.html` in your browser. Browse the site, add products to cart, test checkout.

## Step 2: Update Store Info (3 minutes)
Edit `data/products.json` and find the `store` section at the bottom:
```json
{
  "store": {
    "name": "YOUR STORE NAME",
    "phone": "+977 XXXXXXXXXX",
    "whatsapp": "XXXXXXXXXX",
    "instagram": "your_handle",
    "email": "your@email.com",
    "address": "Your Address"
  }
}
```

## Step 3: Deploy (Choose One)

### Option A: Netlify (Easiest - 1 minute)
1. Go to [netlify.com](https://netlify.com)
2. Drag & drop your website folder  
3. ✅ Live in 30 seconds!

### Option B: GitHub Pages (Free Forever)
1. Create account at [github.com](https://github.com)
2. Create new repository
3. Upload all files
4. Settings → Pages → Enable
5. ✅ Live at `username.github.io/repo`

### Option C: Your Hosting
Upload all files to your hosting via FTP/cPanel.

## 📞 How Orders Work

1. Customer adds to cart
2. Clicks checkout → chooses WhatsApp/Instagram/Viber/Email
3. Pre-filled message sent to YOUR business account
4. You receive order and confirm via chat
5. Customer pays via COD, bank transfer, or mobile wallet

**No payment gateway needed!** ✅
