## What the Product Structure Looks Like:

```json
{
    "products": [
        
        ... (other products) ...
        
        // ← PRODUCT 1: Classic White Shirt (I added this first)
        {
            "id": "tc-100",                    // ← Unique ID number
            "name": "Classic White Shirt",     // ← Product name shown on website
            "sku": "TC-100",                   // ← Stock keeping unit (same as ID)
            "price": 1899,                     // ← Selling price in Rs.
            "originalPrice": 2299,             // ← Original price (before discount)
            "category": "shirts",              // ← Category: shirts, pants, jackets, etc.
            "sizes": [                         // ← Available sizes (array)
                "S",
                "M",
                "L",
                "XL",
                "XXL"
            ],
            "colors": [                        // ← Available colors (array)
                "White",
                "Light Blue"
            ],
            "images": [                        // ← Image URLs (can have multiple)
                "https://images.unsplash.com/photo-1602810318383-e386cc2a3ccf?w=900&q=80"
            ],
            "description": "Crisp white dress shirt perfect for office or formal events. Premium cotton with modern slim fit.",
            "material": "100% Premium Cotton", // ← What it's made of
            "featured": true,                  // ← Show on homepage? true/false
            "isNew": true,                     // ← Mark as "New Arrival"? true/false
            "inStock": true                    // ← Available? true/false
        },    // ← IMPORTANT: Comma here because another product follows!
        
        // ← PRODUCT 2: Black Leather Jacket (I added this second)
        {
            "id": "tc-101",                    // ← Next ID number (tc-100, then tc-101, etc.)
            "name": "Black Leather Jacket",
            "sku": "TC-101",
            "price": 5499,
            "originalPrice": 6999,
            "category": "jackets",             // ← Different category
            "sizes": [
                "S",
                "M",
                "L",
                "XL"
            ],
            "colors": [
                "Black"                        // ← Only one color available
            ],
            "images": [
                "https://images.unsplash.com/photo-1551028719-00167b16eac5?w=900&q=80"
            ],
            "description": "Premium leather jacket with zippered pockets. Modern biker style perfect for cold weather.",
            "material": "100% Genuine Leather",
            "featured": true,
            "isNew": true,
            "inStock": true
        }    // ← NO COMMA here because this is the last product!
        
    ],
    "categories": [ ... ]
}
```

========================================
KEY POINTS TO REMEMBER:
========================================

1. ✅ Each product is wrapped in { curly braces }

2. ✅ Products are separated by COMMAS
   
3. ✅ The LAST product has NO COMMA after it

4. ✅ Each field has a name: "value" format
   
5. ✅ Numbers don't have quotes: "price": 1899
   
6. ✅ Text has quotes: "name": "Classic White Shirt"

7. ✅ true/false don't have quotes: "featured": true

8. ✅ Arrays use [ square brackets ] for lists

========================================
WHAT FIELDS MEAN:
========================================

"id": "tc-101"
    → Unique identifier for this product
    → Use format: tc-XXX where XXX is a number
    → Never repeat the same ID!

"name": "Black Leather Jacket"
    → The name customers see on website

"price": 5499
    → Current selling price in Rupees
    → NO quotes around numbers!

"originalPrice": 6999
    → Price before discount
    → Shows as strikethrough on website
    → Use null if not on sale

"category": "jackets"
    → Must match one of these:
      - "shirts"
      - "t-shirts"
      - "pants"
      - "jackets"
      - "sweaters"
      - "shorts"
      - "accessories"

"sizes": ["S", "M", "L", "XL"]
    → Array of available sizes
    → For shirts/jackets: S, M, L, XL, XXL
    → For pants: 28, 30, 32, 34, 36

"colors": ["Black", "White"]
    → Available color options
    → Can have one or many
    → Names shown to customer

"images": ["https://..."]
    → Image URLs from ImgBB or similar
    → Can have multiple images per product
    → First image is the main one

"description": "Text here..."
    → Product description (2-3 sentences)
    → Appears on product detail page

"material": "100% Cotton"
    → What the product is made of
    → Optional but recommended

"featured": true
    → true = Shows on homepage
    → false = Only shows in category pages

"isNew": true
    → true = Shows "New Arrival" badge
    → false = Regular product

"inStock": true
    → true = Available for purchase
    → false = Shows as "Out of Stock"


========================================
COMMON MISTAKES TO AVOID:
========================================

❌ WRONG: Missing comma
{
    "id": "tc-100",
    "name": "Shirt"
}    ← Missing comma!
{
    "id": "tc-101",
    "name": "Jacket"
}

✅ RIGHT: Comma between products
{
    "id": "tc-100",
    "name": "Shirt"
},    ← Comma here!
{
    "id": "tc-101",
    "name": "Jacket"
}


❌ WRONG: Quotes around numbers
"price": "1899"    // Don't use quotes!

✅ RIGHT: No quotes for numbers
"price": 1899


❌ WRONG: Duplicate IDs
{
    "id": "tc-100",
    ...
},
{
    "id": "tc-100",    // Same ID again!
    ...
}

✅ RIGHT: Unique IDs
{
    "id": "tc-100",
    ...
},
{
    "id": "tc-101",    // Different ID
    ...
}
